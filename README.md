> **[vGuard (Virtualized Intrusion Detection & Prevention System)](https://github.com/EmirEvren/vGuard)**  
> An end-to-end virtualized intrusion detection and prevention system (vIDS/IPS) platform engineered for cloud and virtual network environments. Combines deep packet inspection (DPI), signature matching, Scikit-learn RandomForest AI anomaly detection, honeypot deception traps, and a real-time SSE (Server-Sent Events) SOC dashboard in a unified deployable stack.

* **DPI Engine:** Platform-native packet interception via WinDivert (Windows) and NFQUEUE (Linux) with real-time ACCEPT / DROP / BAN decision filtering
* **AI-Powered Defense:** RandomForest anomaly scoring coupled with 200+ signature-based threat detection rules
* **Real-Time SOC Dashboard:** React 18 + Vite interface featuring live SSE log streaming, attack simulation, and automated IP ban workflows
